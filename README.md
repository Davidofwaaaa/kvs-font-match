# KVS tools [Font match]

A sheet for mixing a group of fonts. Check the fonts, type the text, and run every pair on the grids that are on, or randomize a count from that group. Export the page as SVG or PDF, or export the mixed OpenType files with the grid used for each one.

Open `index.html` in a browser, or serve the folder. GitHub Pages can host it from the repository root.

The typefaces in `fonts/` are OFL. `vendor/opentype.min.js` and `vendor/paper-core.min.js` are MIT.
