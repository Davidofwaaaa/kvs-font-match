# KVS tools [Font match]

A sheet for mixing a group of fonts. Check the fonts, type the text, and run every pair on the grids that are on, or randomize a count from that group. Export the page as SVG or PDF, or export the mixed OpenType files with the grid used for each one.

Specimen is the first screen. Type upper and lower case in the text field. Font rows preview that word, from the bundled set, installed fonts, a local folder, or the Google catalog. Center of mass lines the two glyphs up horizontally and leaves them on the same baseline. Sheet is the batch of every pair. Double-click a cell, or use Open in specimen, to edit that mix large: the grid and guides write back to the cell. Slice stacks images with blend modes, randomizes the grid and the placement, and shows the original beside the slices. Open `index.html` in a browser, or serve the folder. GitHub Pages hosts it from the repository root. The interface is set in Unica77 Mono Trial.

The typefaces in `fonts/` are OFL. `vendor/opentype.min.js` and `vendor/paper-core.min.js` are MIT.
