# KVS tools [Font match]

A sheet for mixing a group of fonts. Check the fonts, type the text, and run every pair on the grids that are on, or randomize a count from that group. Export the page as SVG or PDF, or export the mixed OpenType files with the grid used for each one.

Specimen is the first screen. Type in the middle, pick fonts from the bundled set, a local folder, or the Google catalog, and drag the guides. The grid marks are hairline symbols, and Center of mass lines the glyphs up on their ink. Sheet is the batch of every pair. Slice is the image cutter: the original on the left, the slices on the right. Open `index.html` in a browser, or serve the folder. GitHub Pages hosts it from the repository root. The interface is set in Unica77 Mono Trial.

The typefaces in `fonts/` are OFL. `vendor/opentype.min.js` and `vendor/paper-core.min.js` are MIT.
